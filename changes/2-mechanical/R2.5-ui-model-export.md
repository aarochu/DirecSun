# R2.5: CAD model for the main UI

**Status:** in progress (PR #1 merged; `main` merged into the set branch)
**Files:** `cad/export_ui_model.py` (new), `tools/build-cad.sh` (one more step), `frontend/public/assets/direcsun.glb` (generated, committed like `cad/out`), `cad/out/manifest.json`

## Spec

**Problem:** The main UI's ground station loads `/assets/direcsun.glb` (`frontend/src/data/assets.ts`) and, without it, falls back to a schematic box labelled "SCHEMATIC MODEL, CAD NOT LOADED". The real geometry already exists in `cad/assembly.py`. So the UI shows a placeholder only because nothing exports the CAD in the format it reads.

**Approach:**
- **`cad/export_ui_model.py`.**
  - It builds the assembly's viewing model (printed parts plus the stand-ins, coloured by material) and exports it as binary glTF through CadQuery's assembly export.
  - Orientation and units are converted to what `RealCubeSatModel.tsx` expects: Y-up, metres, origin on the spin axis at the bearing, +X toward the sun-sensor face. These are read from the UI's source, not assumed.
  - It targets under 5 MB, so the page stays fast.
- **`tools/build-cad.sh`** runs the export after the assembly check and records the GLB in `cad/out/manifest.json`, so `tools/check-cad-stale.py` also catches a stale model.
- The rotating wheel is a separate node, so the UI could spin it later. Its name is documented in `cad/README.md`.
