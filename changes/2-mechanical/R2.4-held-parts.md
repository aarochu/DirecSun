# R2.4: Parts held for measurements

**Status:** planned
**Files:** `cad/stack.py` (`MOTOR_BODY_H` and related, `BOARD_W`, `BOARD_T`), `cad/assembly.py`, `cad/out/*`, `cad/README.md` (print plan), `docs/technical-design.md` (§4.9, §4.10, §12.2)

## Spec

**Problem:** `cad/README.md` holds back print plates 5 to 7 because of two measurements:
- the motor height from its mounting face to the top of the spokes, which can move the power deck and therefore the motor deck, the power deck, and the guard;
- the real perfboard width and thickness, which set the avionics deck's card guides.

Printing them on the assumed values risks wasting hours of printer time.

**Approach:**
- Set the measured values in `stack.py`, with an [M] comment and the date. The README already names which parameter each measurement drives.
- Rebuild everything with `tools/build-cad.sh` and let `assembly.py` re-check the clearances. If the motor is taller than 37 mm, the stack above it moves. The battery deck and top deck are then reprinted too, and the print plan in `cad/README.md` says so explicitly.
- Update the print plan tables (plates, times, which plates are now released), and the TD §4.10 "Measure before printing" and §12.2 rows.
