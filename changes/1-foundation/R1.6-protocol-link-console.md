**Status:** done

## Spec

**Problem:** The firmware/ground contract exists only as prose in FD §15. The only working client logic is inline in DirecSun1's page, and it speaks a test format (`type:"telemetry"`, plain-text ACKs) rather than schema v1. Aaron's UI is being built elsewhere and needs a stable module to import, plus something to talk to before Set 3's firmware exists. Safety-relevant client behaviour must live in one tested place: heartbeat, ack matching, no auto-reconnect, and an e-stop that is never queued.

**Approach:**
- **`protocol/schema-v1.json`.** JSON Schema 2020-12 in one file. It dispatches with `oneOf` on `type`, then on `cmd`, and encodes FD §15.3 as amended by R1.2:
  - Messages: `tlm`, `cmd` (`arm`, `disarm`, `estop`, `mode` (with `psi_ref_deg` for SLEW and `input` for MANUAL), `manual`, `respin`, `zero_heading`, `set_params`, `wheel_step`), `ack`, `ping`, `pong`, `event`.
  - Enums for modes (including MANUAL) and for interlock names.
  - Units in each field's description.
  - `additionalProperties: false` everywhere, so drift fails loudly. Bench-only `tlm` fields are declared as optional.
- **Fixtures.** One valid example per message kind. Invalid examples, one per rule: missing `v`, `v` of 2, unknown `type`, unknown `cmd`, a `manual` with two setpoints, a mode outside the enum, and `psi_deg` sent as a string.
- **`tools/check-schema.py`** (venv `jsonschema`) validates the fixtures: every valid one must pass and every invalid one must fail, and it prints both counts. It also validates any JSON-lines file passed as an argument. The link tests use that now, and the firmware host tests will in Set 3.
- **`ground/link/direcsun-link.js`.** An ES module with no dependencies that runs in browsers and in Node 20+. It is the DirecSun1 logic, extracted and grown to v1:
  - Constructor `new DirecSunLink(url, {WebSocketImpl, clock})`, with injection for tests.
  - `connect()` and `close()`.
  - `on(kind, fn)` for `tlm`, `event`, `pong`, `ack`, `state`, and `raw`.
  - `command(name, fields)` returns a Promise that resolves on the `ack` with the matching `seq` and `ok: true`. It rejects with the box's `reason` on `ok: false`, or after a 1 s timeout.
  - `estop()` sends immediately and is never queued or rate-limited. If the socket is not open it throws, so the UI can show that the e-stop did not leave.
  - `manual(setpoint)` is rate-limited to 20 Hz.
  - While open, it pings at 5 Hz and keeps round-trip statistics.
  - It never reconnects on its own: after a close, only an explicit `connect()` opens it again (FD §21 rule 8).
  - Inbound messages with a `v` other than 1 are dropped and surfaced as `raw`.
  - The default endpoint is `ws://direcsun.local:81/`.
- **Link tests.** `ground/link/direcsun-link.test.mjs` runs on `node --test` with a fake WebSocket and mock timers. It covers:
  - ack matching by `seq`, including acks that arrive out of order;
  - timeout rejection;
  - 5 Hz ping cadence over 10 simulated seconds;
  - e-stop on a closed socket throwing;
  - no reconnect after a close;
  - `tlm` dispatch;
  - the manual rate limit.

  When `DIRECSUN_LINK_CAPTURE` is set, every outbound message is also appended to that JSON-lines file. `tools/check-link.sh` runs the tests with capture on, then runs `check-schema.py` on the capture.
- **`tools/mock-box.py`** (pending `_set.md` open question 1). A protocol stub, not a plant model, built on `websockets`. It listens on port 8081 by default, because binding port 81 needs root on Linux; `--port` overrides it. It:
  - streams 50 Hz `tlm` with plausible values (a slow heading sine, vbat 10.1);
  - follows FD §13.1 for `arm`, `disarm`, `estop`, and `mode`: it goes SAFE to SPINUP, then READY after 2 s, and posts the matching `ack` and `event`;
  - enforces the controlling-client rule and the 1 s heartbeat (HEARTBEAT_LOST);
  - with `--selftest`, validates one of each outbound message kind against the schema.
- **`ground/console/index.html`.** Copied from DirecSun1 `web/index.html` with its visual design kept. The inline socket code is replaced by an import of `../link/direcsun-link.js`. It shows:
  - the v1 fields: mode, psi_deg, rate_dps, wheel_rpm, vbat, loop_us, flags;
  - a raw-frame log;
  - Arm, Disarm, and Mode READY buttons, plus E-stop (also bound to the space bar);
  - each command's ack result;
  - round-trip time.

  ES modules cannot load over `file://`, so the README says to serve it with `python3 -m http.server` from the repo root.
