# R3.6: Mode machine, interlocks, ramp-down, parameters, Hall bench bypass

**Status:** planned
**Files:** `firmware/components/direcsun_core/{include/direcsun/core/{modes,interlocks,params}.hpp,src/{modes,interlocks,params}.cpp}`, `firmware/test/host/{test_modes,test_interlocks,test_params}.cpp`, `docs/technical-design.md` (§6.6, §6.7, §12.4 rows), `docs/firmware-design.md` (§13.1, §14.1, §16, §19.1, §23 rows)

## Spec

**Problem:** Safety lives in this logic. Every path that ends a spin must end in DShot 0, and nothing may resume motion without a fresh `arm` (FD §7.1, §21). It must exist, host-tested to its thresholds, before any rung spins the wheel. The Hall sensor cannot be mounted yet, so rung 1 needs a bench bypass. The owner approved one on 2026-10-10. It must be impossible to reach by accident.

**Approach:**
- **Modes (FD §13.1, §13.2, §13.5).**
  - States: SAFE, SPINUP, READY, and MANUAL with input `throttle`, `wheel`, or `rate`.
  - `mode` commands for DETUMBLE, HOLD, SLEW, and SUN_POINT, and the `respin` command, are refused with `reason:"not implemented"` until Sets 4 and 5.
  - Guards follow FD §13.1: `arm` needs SAFE, |ω̂| < 5 deg/s, vbat above 9.6 V, and no latched fault.
  - Spin-up completes after 0.5 s within 5% of the target speed.
  - A MANUAL input is refused with "input not available" until its rung (R3.7 to R3.9) registers itself as built.
  - The mode machine is a pure function of state, inputs, the tick, and the parameters, so every row is host-testable.
- **Interlocks (FD §14.1, §14.2).** Evaluated every tick after the controller.
  - Hard faults set throttle 0 in the same tick, latch the fault, set the mode to SAFE, and post an event: OVERSPEED, UNDERSPEED, BATTERY_LOW, IMU_SILENT, TILT, HALL_SILENT, CONTROL_STALL.
  - ESTOP, HEARTBEAT_LOST, and `disarm` start the open-loop ramp-down instead: throttle_0 × (1 − t / 5 s), mapped to 0 below 48, then DShot 0. A hard fault during the ramp ends it at once.
  - MOMENTUM_NEAR_LIMIT is a flag only.
  - Latches clear as FD §14.1 says.
- **Parameters (FD §16).**
  - Defaults, ranges, and validation for every key, with NVS persistence under namespace `direcsun` with `param_version`. A mismatched version loads the defaults and posts PARAMS_RESET.
  - `set_params` is accepted in SAFE only and is all-or-nothing: one bad key rejects the whole set, with the key named.
  - `omega_cap_rpm` cannot be raised above 4000 by any path.
  - New key `spinup_throttle`, used by R3.7: the open-loop throttle that SPINUP ramps to. Its default is the bench-safe 300, until T-5 measures it.
- **Hall bench bypass [D, approved 2026-10-10; TD and FD revision logged in this feature].**
  - Parameter `hall_installed`, default true. It is never persisted: every boot sets it true.
  - It can be set false only by `set_params` in SAFE, and only while `bench_mode` is true.
  - While it is false:
    - `arm` is refused unless `bench_mode` is true.
    - Only MANUAL `throttle` is available.
    - OVERSPEED, UNDERSPEED, and HALL_SILENT are suspended, and the event stream and `tlm` flags show HALL_BYPASS on every frame.
    - SPINUP is open-loop: ramp to `spinup_throttle`, then READY after the ramp plus 0.5 s, with no speed check.
    - Every throttle the controller emits is clamped to `min(manual_throttle_max, kBypassThrottleMax)`. `kBypassThrottleMax` is a `constexpr`, not a parameter, so no command can raise it. The proposed value is 400; see `_set.md` open question 1.
  - TD §6.6 and §6.7 and FD §13.1, §14.1, and §16 gain the bypass, with a §12.4 and §23 row each.

## Tests
- [ ] HT-7, modes, on the host:
  - Every transition row of FD §13.1 that exists in this set fires on its guard.
  - Every refusal returns its exact reason string: SAFE-only commands, a still box, battery, latched fault, not controlling client, input not available, not implemented.
  - FR-2 timing: a command applied in the tick after it is dequeued.
- [ ] HT-8, interlocks, on the host:
  - Each hard fault trips at its threshold and does not trip 1% inside it.
  - Throttle is 0 in the tripping tick.
  - The ramp-down reaches 0 at 5.0 s ± 1 tick and ends early on a hard fault.
  - ESTOP is accepted in every state.
  - No path returns the mode to anything but SAFE after a fault without a new `arm`. Positive control: removing a latch in a test build makes that check fail.
- [ ] HT-10 on the host: HALL_SILENT trips in SPINUP with throttle above the low-limit feed-forward and no edges for 500 ms, and does not trip at 495 ms.
- [ ] Parameters on the host:
  - Range validation rejects one out-of-range key and applies nothing.
  - `omega_cap_rpm = 4001` is rejected by every route.
  - A `param_version` mismatch loads the defaults.
- [ ] Bypass on the host, property tests over 10,000 random parameter sets and command sequences:
  - Throttle never exceeds `kBypassThrottleMax` while bypassed.
  - `hall_installed=false` is refused outside SAFE and without `bench_mode`.
  - A fresh boot state always has `hall_installed=true`.
  - Positive control: a test build with the clamp removed makes the property fail.
- [ ] Docs: the bypass appears in TD §6.7 and FD §14.1 and §16 bodies, plus the log rows, and `grep -c "—"` on both docs is still 0.
