# R3.9: Rate loop, closed-loop simulation, sign check

**Status:** planned
**Files:** `firmware/components/direcsun_core/{include/direcsun/core/controllers.hpp,src/controllers.cpp,src/control.cpp}`, `firmware/test/host/{plant_sim.hpp,test_closed_loop.cpp}`, `docs/technical-design.md` (§12.2: s_w, gains)

## Spec

**Replan 2026-10-10:** the main UI (`frontend/`) became the demo, so the MANUAL teleop input this feature first carried moves to Set 5 (R5.2). This feature keeps the loop, its tests, and the bench tooling that the UI's judge sequence (Set 4) depends on.

**Problem:** The rate loop is the first loop that closes through the box itself. That makes it the first point where the R-1 sign error (TD §12.4) turns damping into acceleration. The same rate loop with ω_cmd = 0 is DETUMBLE (Set 4), and the attitude loop for the UI's judge sequence (Set 4) wraps around it.

**Approach:**
- **Rate loop** (FD §12.1 steps 2 and 3, §12.2, §12.3):
  - τ_cmd = K_ω e + K_i ∫e, with e = ω_cmd − ω̂, limited to ±31 mN·m.
  - Ω_ref += −s_w · τ_cmd · (1/I_w + 1/I_b) · Δt, clamped to [Ω_low, Ω_cap].
  - Conditional integration stops when τ_cmd saturates or Ω_ref sits on a clamp in the direction that would need more, which sets MOMENTUM_SATURATED.
  - Starting gains: K_ω = 0.0129 and K_i = 0.0163 (FD §12.2), scaled by `rate_gain_scale` (new parameter, default 0.2 for the first runs, as in FD §12.5).
- **READY holds rate.** READY now runs this loop at ω_cmd = 0, which is what TD §6.6 asks for. ω_cmd is an input of the loop, so Set 4's attitude loop and Set 5's MANUAL `rate` can drive it later.
- **Plant simulation** (`plant_sim.hpp`, FD §19.1 HT-5 and HT-6, moved here from Set 4):
  - The two-body plant of TD §3.1, with I_b = 1.03e-3 and I_w = 6.50e-5.
  - Coulomb friction from 0 to 3 mN·m.
  - The wheel loop modelled as a first-order lag at its measured bandwidth (2 Hz until R3.8 measures it).
  - Gyro noise, and the 8.3 ms DLPF delay.
- **Sign check** (FD §12.5), on the turntable, with Julian present:
  1. Pinned, a `wheel_step` confirms the wheel follows.
  2. Unpinned at `rate_gain_scale` 0.2, push the rig counter-clockwise by hand. Ω_ref must move so the reaction opposes the push, and ω̂ must decay. If ω̂ grows instead, e-stop, flip s_w, and repeat.
  3. Record s_w in NVS and TD §12.2.

## Tests
- [ ] HT-5 (sim): in READY (ω_cmd = 0), a 1 rev/s initial spin decays below 5 deg/s within 5 s (PR-1) for friction 0, 1, and 3 mN·m. A ±30 deg/s ω_cmd, set through the loop's input in the sim, is tracked within 10% after 1 s. Ω_ref never leaves [Ω_low, Ω_cap].
- [ ] HT-6 positive control (sim): the same detumble with s_w flipped diverges, |ω| grows past 2 rev/s. Per FD §21 rule 5, the suite counts only if this test fails as expected.
- [ ] Host anti-windup: a sustained command into MOMENTUM_SATURATED does not wind up. On release, ω̂ returns toward 0 without a lurch larger than 20 deg/s.
- [ ] Hardware sign check on the turntable, with Julian's explicit go: steps 1 to 3 of the Approach, with the outcome and s_w recorded. Marked BLOCKED until the turntable and Hall exist.
- [ ] Hardware on the turntable: in READY, a hand spin of about 0.5 rev/s is damped below 5 deg/s within 5 s, and a 10 s hold shows no limit cycle larger than ±2 deg/s.
