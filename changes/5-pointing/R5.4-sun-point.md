## Spec

FD §11.4 and TD §6.4 and §6.5 define the sun angle from the two OP550s and SUN_POINT, the first mode TD §11.4 drops if time runs short. The ADC already reads both channels (R3.3). This feature adds the calibration, the estimate, and the mode.

- **Estimate.** d = (A − B)/(A + B); valid only when A + B is above 0 and `light_threshold` (mV) and d is inside the table. The table (`sun_cal`, up to 8 points, T-10) is piecewise linear and never extrapolated. With no table, the identity table maps d of +1 to 90 deg clockwise on the wire.
- **Sign.** The wire sun angle is how far the box must turn clockwise to face the lamp. The core keeps the table counter-clockwise positive; the protocol layer negates it in `set_params` and `tlm.sun_deg`.
- **Parameters.** `sun_cal` and `light_threshold` are persisted; the layout changes, so `param_version` becomes 3 and the first boot posts `PARAMS_RESET` once [D].
- **SUN_POINT.** From READY, on the closed wheel loop (`wheel loop not available` otherwise), with a valid sun now (`sun not valid`). The attitude block takes the sun angle as the error through HOLD's 1 deg deadband, into the same rate loop (FD §12.1). `psi_ref_deg` is null. If the sun is invalid for 0.5 s the box returns to READY with event cause `sun_invalid`; a valid reading restarts the timer. `mode READY`, `disarm`, `estop` and every interlock act as in HOLD.
- **Telemetry.** `sun_deg` and `sun_valid` are live in every mode from the moment the sensors read, not only in SUN_POINT, so T-10 can be watched from the UI.

## Tests
- [x] Host: identity table, threshold, no light, NaN and negative inputs; a three-point table interpolates and is invalid outside its range.
- [x] Host: validation rejects non-increasing d, a non-monotonic angle, one point, a negative threshold; a falling table is accepted; the persisted layout round-trips.
- [x] Host protocol: `set_params` decodes the wire (clockwise) table into the internal frame, `tlm.sun_deg` encodes it back, null when invalid.
- [x] Host supervisor: entry refusals `not in READY`, `wheel loop not available`, `sun not valid`; no return to READY at 490 ms of invalid sun, a valid sample restarts the timer, return with `sun_invalid` at 0.5 s.
- [x] Host plant (BoxRig with a lamp): the box turns toward a lamp 40 deg either side, at friction 0 and 2 mN·m, and holds within 2 deg and under 3 deg/s after 5 s with no latched fault.
- [x] Mock (`--lamp DEG`): refusals as above, convergence to a lamp either side, `sun_invalid` exit; fixtures validate; `check-all` passes.
- [ ] Hardware T-10 (TD §9.1): lamp at 1 m, box stepped −60 to +60 deg; the difference signal is monotonic across +-30 deg; write `sun_cal` and `light_threshold`.
- [ ] Hardware, Julian's go: SUN_POINT tracks a moved lamp on the turntable and returns to READY when the lamp is covered.
