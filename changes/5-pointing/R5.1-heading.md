## Spec

FD §10.2 and §11.3 and TD §6.4 define the compass heading and the complementary filter. R4.2 shipped a gyro-only heading with the `HEADING_GYRO` flag; this feature adds the compass without disturbing the relative HOLD and SLEW the judge sequence uses.

- **Axis map.** `mag_axis_map`: box X, Y, Z in sensor axes, default `["+x","-y","-z"]` for the flipped deck. It must be a permutation with signs +-1.
- **Calibration.** `mag_cal`: hard-iron offset (box frame, counts) and the 2 x 2 soft-iron matrix. Until it is set, fusion is off and the heading is gyro-only as before. A singular matrix is refused.
- **Heading.** ψ_mag = atan2(-h_y, h_x), h = soft x (box - offset), counter-clockwise positive so a CCW turn raises it. The estimator averages the samples in each 20 ms window and applies ψ̂ += 0.01 x wrap(ψ_mag - ψ̂); the first fix sets ψ̂ to ψ_mag. The compass counts as fused for 0.5 s after each step.
- **Flags and telemetry.** `HEADING_GYRO` is set whenever the compass is not fused (so it disappears once T-9 is done and the compass is live); `mag_deg` is the wrapped compass heading, clockwise positive on the wire, null when not fused.
- **HOLD and SLEW.** Unchanged: relative to the last `zero_heading`, which is an offset the supervisor keeps on top of the (now absolute) estimator heading, so a zero and the fusion never conflict. What changes is that the reference no longer drifts with the gyro, which is PR-3.
- **Calibration tool.** `tools/fit-mag-cal.py` takes a bench-mode capture of a 360 degree turn, fits the ellipse, prints the `set_params` JSON, and checks the compass against the gyro heading to 3 degrees (T-9). Its `--selftest` rejects a half turn, a mirrored axis map and a flat field.
- **Persistence.** `param_version` is 4.

## Tests
- [x] Host: the arithmetic recovers the heading to 0.3 deg through the flipped-deck map, a CCW turn raises it monotonically, and with a hard- and soft-iron distortion the calibrated heading is within 0.5 deg while the uncalibrated one is off by more than 5 deg.
- [x] Host filter: with a 0.5 deg/s unknown gyro bias for 60 s the fused heading stays within 1.5 deg (the bias times tau) and the gyro-only heading walks away by more than 10 deg; the first fix sets the heading; fusion lapses 0.5 s after the last sample.
- [x] Host PR-3 (T-17 form): a 60 s HOLD against a 0.3 deg/s unlearned gyro offset, with three 10 mN·m pokes, stays within 2 deg outside the 2 s after each poke only with the compass fused; the gyro-only control drifts more than 5 deg.
- [x] Host parameters and protocol: wire decode of both keys, validation (non-permutation, singular matrix, bad sign), persistence round trip, `tlm.mag_deg` sign and null, `HEADING_GYRO` follows fusion.
- [x] `tools/fit-mag-cal.py --selftest`; mock and fixtures; `check-all`.
- [ ] Hardware T-9: a 360 degree turn at 1600, 2400 and 3600 rpm in turn, three fits compared for a speed-dependent offset; the residual against the gyro heading is within 3 deg; if the fits differ, FD §11.3's per-speed correction table becomes a new feature.
- [ ] Hardware T-17: a 60 s HOLD and three pokes on the turntable holds within 2 deg outside the 2 s after each poke.
