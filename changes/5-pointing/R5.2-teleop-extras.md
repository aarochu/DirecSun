## Spec

FD §13.5 defines three MANUAL inputs. Set 3 built `throttle`; the main UI already offers `wheel` and `rate` in its mode menu (`frontend/ground-station/src/hardware/modes.ts`). This feature builds them on the existing wheel and rate loops. No new loop and no schema change.

- **Built inputs.** `kAllBuiltInputs` (throttle, wheel, rate) replaces `kRungOneBuiltInputs` in the control task. With the Hall bypassed only `throttle` is offered (unchanged).
- **Entry.** From READY by the controlling client. `wheel` and `rate` need the closed wheel loop, so without the T-5 table the ack is `wheel loop not available` (as for HOLD, SLEW, DETUMBLE).
- **`wheel`.** The wheel loop alone: the rate loop is stopped. Ω_ref moves toward the setpoint (clamped to [Ω_low, Ω_cap] by the supervisor and to the V-52 floor and the cap by the controller) at `kManualWheelRampRpmPerS` = 1000 rpm/s. Entry starts from the measured wheel speed, so entry is not a step. [D] 1000 rpm/s is gentler than the torque limit (4842 rpm/s) and lets the operator watch the box respond.
- **`rate`.** The rate loop with ω_cmd equal to the setpoint (limited to +-90 deg/s). After 250 ms without a setpoint the supervisor sets ω_cmd to 0 and `MANUAL_STALE` (HT-11, unchanged).
- **Unchanged:** setpoint spacing, heartbeat, exit, and every interlock.

## Tests
- [x] Host: entry refused with `wheel loop not available` for `wheel` and `rate` without the table, `throttle` still accepted; the HT-11 clamp and staleness tests run on a characterised box.
- [x] Host plant (`test_teleop_extras.cpp`): `wheel` ramps the reference 250 to 340 rpm in 0.3 s for an 800 rpm step, reaches it, turns the free box the opposite way, and a 9000 rpm setpoint is clamped to the cap with no interlock. `rate` tracks +-30 deg/s within 10 % after 2.5 s and falls to rest after the setpoint stops (MANUAL_STALE set).
- [x] Mock: `mode MANUAL` with `wheel` or `rate` refuses `wheel loop not available` on an uncharacterised box; `mock-box.py --selftest` passes.
- [ ] Hardware, Julian's go: on the turntable in READY at bias, MANUAL `wheel` +300 rpm turns the box against the wheel's change and settles; MANUAL `rate` +-30 deg/s is tracked; releasing the control brings the box to rest within 5 s.
