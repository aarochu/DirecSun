## Spec

FD §13.1–13.2 and TD §6.6 define DETUMBLE as a distinct wire mode using the same zero-rate wheel and rate cascade as READY. Accept it only from READY after the controlling-client check. Report a mode event and DETUMBLE telemetry. `mode READY` returns to READY; disarm, e-stop, heartbeat loss, and interlocks retain the existing SAFE behavior. Other entry states return the existing `not in READY` refusal. The mode requires the wheel loop so its behavior is consistent with READY's closed-loop control. Include DETUMBLE in momentum status because the wheel runs there. Keep SUN_POINT deferred.
